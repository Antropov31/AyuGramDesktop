# FluxiGram

Форк AyuGram Desktop (который сам форк Telegram Desktop). Цель: расширенная
кастомизация клиента, общий фид каналов и набор приватных фич.

Базовый коммит апстрима: `b25513a` (AyuGram/AyuGramDesktop).

---

## Архитектура (где что лежит)

Все доработки AyuGram живут в `Telegram/SourceFiles/ayu/`:

- `ayu_settings.{h,cpp}` — модель настроек (сериализация в JSON, геттеры/сеттеры).
- `ui/ayu_logo.{h,cpp}` — переключатель иконки/брендинга приложения.
- `ui/settings/` — экраны настроек (`settings_main`, `settings_appearance`,
  `settings_general`, `settings_chats`, `settings_other`, `settings_filters`).
- `ui/settings/ayu_builder.{h,cpp}` — декларативный билдер строк настроек.
- `features/` — функциональные модули.
- `ui/context_menu/` — доп. пункты контекстного меню.
- `ui/message_history/` — локальная история правок/удалений сообщений.

Локализация: репозиторий `AyuGram/Languages` (форкнут).

## Фичи: статус и план

### 0. Меню/брендинг FluxiGram  — ДЕЛАЕМ ПЕРВЫМ ✅
В настройках внешнего вида AyuGram есть выбор иконки приложения
(AyuGram / exteraGram / ...). Добавляем третий вариант `FluxiGram`.

Что нужно:
1. Новый элемент в enum брендинга в `ui/ayu_logo.h`.
2. Ветка отрисовки/выбора в `ui/ayu_logo.cpp`.
3. Ассеты иконки (`.ico`/`.png`/`.svg`) в ресурсах.
4. Строка локализации в `AyuGram/Languages`.
5. Подключение пункта в `ui/settings/settings_appearance.cpp`.

Сложность: низкая. Полностью клиентская. Хороший первый PR.

### 1. Больше кастомизации (перестановка пунктов настроек) — ДЕЛАЕМ ✅
Переписать `ayu_builder` так, чтобы секции/строки можно было
переупорядочивать drag-and-drop, а порядок сохранять в `ayu_settings`.

Что нужно:
- Поле `settingsOrder` (список ID секций) в модели настроек.
- Reorderable-список в билдере (в TDesktop есть `Ui::VerticalLayoutReorder`).
- Применение сохранённого порядка при рендере.

Сложность: средняя. Клиентская. Полностью реально.

### 2. Общая лента каналов по датам — ДЕЛАЕМ ✅
Виртуальный чат/экран, агрегирующий посты из всех каналов-подписок,
отсортированные по дате.

Что нужно:
- Новый модуль в `features/` (сбор сообщений из диалогов типа channel).
- Отдельный псевдо-диалог в списке чатов или пункт меню.
- Подгрузка истории и сортировка по timestamp.

Сложность: высокая, но клиентская и выполнимая. Данные уже есть локально
(клиент и так получает посты каналов).

### 3. Фичи Telegram Premium — НЕЛЬЗЯ ❌
Premium гейтится на СЕРВЕРЕ Telegram (лимиты загрузок, премиум-стикеры,
большие файлы, голосовая транскрипция и т.д.). Форк клиента это не
разблокирует. Можно нарисовать UI, но сервер всё равно откажет.
Вывод: не делаем, это тупик. Вместо этого — клиентские аналоги, что
реально (папки, кастомные эмодзи-паки локально, и т.п.).

### 4. Чат только для пользователей FluxiGram — ПОЧТИ НЕЛЬЗЯ ⚠️
Сервер Telegram не доверяет и не проверяет, каким клиентом ты сидишь.
Любой чат открывается официальным клиентом. "Защита по клиенту"
обходится тривиально. Максимум — клиентская заглушка (скрывать чат,
если не FluxiGram), но это не настоящая приватность.
Альтернатива, которая реально работает: внешний бот/мини-апп с проверкой,
либо MTProto-слой с собственным шифрованием поверх. Это отдельный большой
проект, не фича форка.

### 5. Идеи от меня (всё клиентское, реально) 💡
- Локальный замок чатов по PIN/биометрии (скрытие выбранных диалогов).
- Кастомные горячие клавиши.
- Встроенный менеджер тем с импортом/экспортом.
- Расширенное локальное логирование правок/удалений (развить
  `message_history`).
- Быстрые "саппресс-режимы": скрыть онлайн/прочитано точечно по чату.

## Порядок работ

1. Брендинг FluxiGram (фича 0).
2. Перестановка настроек (фича 1).
3. Локальный замок чатов (фича 5).
4. Общая лента каналов (фича 2).
5. Премиум/клиент-онли (3, 4) — отклонены или вынесены за рамки.

## Сборка
См. `docs/` апстрима. Это C++/Qt проект, собирается через CMake,
требует сабмодули (`.gitmodules`). Без локальной сборочной среды
фичи не скомпилировать — кодовые правки тестируются только локальной сборкой.
