# FluxiGram

Форк AyuGram (который сам форк Telegram Desktop) с дополнительным брендингом,
расширенной кастомизацией и набором клиентских фич.

> Базовый код: AyuGram by @Radolyn. Уважайте оригинального автора и лицензию (GPLv3).

## 1. Расширенная кастомизация (перестановка настроек)

**Реально, чисто клиентское.** Меню настроек AyuGram строится через декларативный
`SectionBuilder` / `AyuSectionBuilder` (см. `settings_appearance.cpp`,
`ayu_builder.cpp`). Каждый пункт имеет стабильный `id` (напр. `u"ayu/materialSwitches"_q`).

План:
1. Завести `AyuSettings`-поле `settingsOrder` — массив `id` в пользовательском порядке.
2. В билдере секции сортировать виджеты по этому массиву перед добавлением.
3. Добавить режим "редактирования": drag-handle у каждой строки (Qt drag&drop по
   `Ui::VerticalLayout`), на отпускании — пересчёт `settingsOrder` и `save()`.
4. Кнопка "Сбросить порядок".

Точки входа: `Telegram/SourceFiles/ayu/ui/settings/ayu_builder.cpp` и
`settings/settings_builder.cpp`.

## 2. Общая лента всех каналов по датам

**Реально, клиентское.** Это виртуальный объединённый фид сообщений из всех
каналов-подписок, отсортированный по дате.

План:
1. Новый раздел в drawer/меню: "FluxiGram Feed".
2. Итерировать диалоги (`Data::Session::chatsList`), отфильтровать каналы
   (`peer->isChannel() && !isMegagroup`).
3. Тянуть последние сообщения через уже существующий механизм истории, мерджить
   в единый список по `date`.
4. Рендерить переиспользуя `HistoryView` элементы; по клику — переход в исходный канал.
5. Подгрузка по скроллу (пагинация по дате).

Большой объём, но не требует ничего серверного сверх обычного API.
Отдельный модуль: `Telegram/SourceFiles/ayu/features/feed/`.

## 3. Фичи Telegram Premium — НЕВОЗМОЖНО в клиенте

Premium гейтится **на сервере** Telegram, не в клиенте:
- увеличенные лимиты (загрузки, папки, аккаунты, длина подписи) проверяет сервер;
- премиум-стикеры/реакции/эмодзи-статусы валидируются сервером;
- флаг `user.premium` приходит от сервера и не подделывается клиентом.

Форк клиента может нарисовать UI, но функционально это не разблокирует — сервер
отклонит запрос. Любые "обходы" либо не работают, либо ведут к бану аккаунта.
**Не реализуется честно.** Альтернатива: косметические клиентские фичи (кастомные
реакции локально, свои эмодзи-паки в интерфейсе) — но это не настоящий Premium.

## 4. Чат только для пользователей FluxiGram — НЕВОЗМОЖНО надёжно

Сервер Telegram не знает и не доверяет, каким клиентом подключается пользователь.
Любой чат/канал открывается официальным клиентом и любым форком. "Тип клиента"
не является доверенным признаком на стороне сервера.

Что *можно* (но это не защита, а косметика):
- клиентская "заглушка": FluxiGram прячет/показывает определённый чат по локальному
  флагу — но обладатель обычного ТГ всё равно туда зайдёт;
- e2e-маркер: слать в чат сообщения со скрытым префиксом, который рендерит только
  FluxiGram — но контент всё равно виден всем.

Настоящий "закрытый клуб" требует **своего сервера/бота** с авторизацией, а не
форка клиента. Если хочешь — можно спроектировать бота-гейткипера отдельно.

## 5. Доп. идеи (мои)

Всё клиентское и реально:
- **Локальный замок чатов**: скрытие выбранных чатов за PIN/биометрию (флаг в
  `AyuSettings`, фильтр в списке диалогов).
- **Кастомные горячие клавиши**: расширить `default_shortcuts-custom.json` +
  редактор в настройках.
- **Менеджер тем**: быстрый свитчер сохранённых `.tdesktop-theme` прямо из drawer.
- **Профили внешнего вида**: пресеты настроек (id-наборы из фичи №1), переключаемые
  одним кликом.
